## What I understood

A schema is like a box that stores database objects such as tables, indexes, views, sequences, and code. Oracle lets me inspect this box with dictionary views like user_objects and user_tables can print the commands needed to recreate the objects, but I must clean the output so it works in another schema. When moving a schema, the safest idea is to create basic objects first and add dependent objects later.
