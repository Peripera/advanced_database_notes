# Lesson 03: SQLAlchemy ORM + Alembic Migrations

## Topics covered

SQLAlchemy ORM models, relationships, foreign keys, Alembic migrations, upgrade, downgrade, CRUD operations, and rollback.

## What I understood

In this lesson I understood that ORM lets me work with database tables like Python classes instead of writing every SQL command by hand. The models describe the tables, and relationships connect objects like users, tasks, teams, and comments. I also understood that Alembic migrations are like saved steps for changing the database structure, so the schema can move forward with upgrade or go back with downgrade.

## What is still confusing

I still need more practice understanding how Alembic detects changes automatically. Sometimes I am not fully sure if a change in the Python model will create the exact migration I expect. I also want to practice more with rollback because deleting a column or table can also delete data.
